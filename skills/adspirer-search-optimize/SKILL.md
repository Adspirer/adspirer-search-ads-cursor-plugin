# Evidence-backed optimization

Load adspirer-search-mcp. Confirm account, time window, currency, timezone, objective,
and conversion definition. For Google, discover reporting tools or use the advertised
get_campaign_performance schema. Review search terms, costs, conversions, CPA/ROAS,
negative candidates, budget pacing, and data sufficiency where supported.
Account for conversion lag, small samples, attribution differences, and missing data.
For Microsoft, use discovered listing/inspection operations to review configuration;
do not fabricate performance metrics or assume a reporting tool exists.
Return findings, evidence, proposed changes, and expected tradeoffs, not guaranteed lifts.
A request to analyze does not authorize budget, bid, keyword, pause, or delete operations.
Get explicit approval and readback for each agreed change. Offer recurring reviews, but do
not create schedules or unattended spending policies without an explicit request.
